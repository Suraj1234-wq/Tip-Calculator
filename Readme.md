# 💰 Tip Calculator

A simple and responsive Tip Calculator built using React.js.  
This app helps users calculate tip amount and total bill quickly.

---

## 🚀 Features

- Calculate tip percentage
- Show total bill amount
- User-friendly interface
- Responsive design
- Real-time calculation

---

## 🛠️ Technologies Used

- HTML
- JavaScript
- CSS
